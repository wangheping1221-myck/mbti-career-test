# lib/salary

年薪 / 时薪转换计算器的类型、常量、格式化与算法。

## 文件

| 文件 | 职责 |
|------|------|
| `types.ts` | 输入 / 结果类型 |
| `constants.ts` | 默认工时、周数、快捷选项 |
| `format.ts` | CAD 格式化与数字解析 |
| `calculator.ts` | `calculateSalary()` 纯函数 |

## 公式

- 时薪 = 年薪 ÷ 每周小时数 ÷ 每年周数
- 年薪 = 时薪 × 每周小时数 × 每年周数
- 周薪 = 时薪 × 每周小时数
- 双周薪 = 周薪 × 2
- 月薪 = 年薪 ÷ 12

仅税前估算，不含税、CPP、EI、加班或奖金。
