# lib/calculators

所有计算器**算法入口与共享计算工具**放在这里。

## 强制原则

1. **不得**把计算逻辑写在 `app/**/page.tsx` 或 UI 组件里。
2. `page.tsx` 只负责渲染、收集输入、调用 lib 中的纯函数。
3. 算法应纯函数化，便于单测与后续更新。

## 未来模块划分

| 目录 | 职责 |
|------|------|
| `lib/salary/` | 年薪 / 时薪 / 周薪等换算 |
| `lib/clb/` | 各考试成绩 ↔ CLB 对照与转换 |
| `lib/oinp/` | OINP EOI 评分规则与计分（须官方来源） |

本目录（`lib/calculators/`）可放跨工具的共享类型、校验辅助函数等；各政策/公式细节仍归入上表独立目录。

## 当前状态

仅架构占位，**无业务算法代码**。
